# 🎓 Trilha de aprendizado do ProgramaBot

Bem-vindo! Esta pasta é o "curso" do ProgramaBot. **Você não precisa saber programar para começar.** Siga os módulos na ordem e, quando quiser, volte para revisar.

## Mapa da trilha

```
1. getting-started      → instalar tudo e colocar SEU bot online
2. programming-basics   → o que é programar, lógica, algoritmos
3. python               → a linguagem, do básico ao intermediário
4. libraries            → as bibliotecas que o bot usa
5. discord-development  → como bots do Discord funcionam
6. code-explanation     → cada arquivo do ProgramaBot, explicado
7. exercises            → pratique (com soluções separadas)
8. best-practices       → segurança, organização, testes
```

## Como estudar

1. **Coloque o bot no ar primeiro** (módulo 1). Ver algo funcionando motiva.
2. **Estude um conceito** (módulos 2 e 3).
3. **Encontre esse conceito no código real**. Cada aula tem uma seção "No ProgramaBot" apontando onde ele aparece.
4. **Modifique algo pequeno** e veja o resultado no Discord.
5. **Faça os exercícios** antes de olhar as soluções.

Prefere vídeos? Veja as [playlists recomendadas](../resources/youtube-playlists.md). Encontrou uma palavra estranha? Consulte o [glossário](../resources/glossary.md).

## Tempo estimado

Cada pessoa tem seu ritmo. Como referência para quem estuda cerca de 1 hora por dia:

| Etapa | Duração aproximada |
|---|---|
| Primeiros passos | 1 a 2 dias |
| Fundamentos de programação | 1 semana |
| Python básico (aulas 1 a 8) | 2 a 3 semanas |
| Python intermediário (aulas 9 a 13) | 2 semanas |
| Desenvolvimento para Discord + código do bot | 2 a 3 semanas |
