# 🌐 Sites úteis

Ferramentas e referências gratuitas que ajudam no dia a dia.

## Para praticar e testar

| Site | Para quê |
|---|---|
| [regex101](https://regex101.com/) | Testar expressões regulares (escolha o *flavor* "Python"); explica cada parte do padrão |
| [Python Tutor](https://pythontutor.com/) | Visualizar, passo a passo, o que acontece na memória quando o código roda. Ótimo para entender laços e funções |
| [DB Browser for SQLite](https://sqlitebrowser.org/) | Abrir o arquivo `data/programabot.db` e ver as tabelas |

## Para entender o Discord

| Site | Para quê |
|---|---|
| [Discord Developer Portal](https://discord.com/developers/applications) | Criar e configurar a aplicação do bot |
| [Documentação do Discord](https://discord.com/developers/docs/intro) | Referência oficial da API |
| [discord.py: exemplos](https://github.com/Rapptz/discord.py/tree/master/examples) | Código de exemplo oficial |

## Para tirar dúvidas

| Site | Para quê |
|---|---|
| [Stack Overflow em Português](https://pt.stackoverflow.com/) | Perguntas e respostas de programação em português |
| [Stack Overflow](https://stackoverflow.com/) | A maior base de perguntas e respostas (em inglês) |
| [Issues do ProgramaBot](https://github.com/TalissonDeevv/ProgramaBot/issues) | Dúvidas e problemas específicos deste projeto |

> Antes de perguntar: pesquise a mensagem de erro, leia a [página de problemas comuns](../education/getting-started/09-problemas-comuns.md) e, ao perguntar, mostre o código e o erro completo, **sem** o token.
