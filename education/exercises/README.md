As soluções comentadas estão em [`solucoes/`](solucoes), em arquivos separados.

## Como fazer os exercícios do bot

1. Crie uma branch para estudar: `git switch -c estudo/exercicios`.
2. Faça as mudanças e reinicie o bot para testar.
3. Rode `python -m pytest`. Se você criou um comando novo, os testes vão lembrar você de documentá-lo e de colocá-lo no `/help`. Isso faz parte do exercício!

## Formato de cada exercício

**Objetivo** · **Nível** · **Conteúdos necessários** · **Enunciado** · **Arquivos envolvidos** · **Dicas** · **Resultado esperado** · link para a **solução**
