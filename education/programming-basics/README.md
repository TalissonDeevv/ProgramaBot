# 🧠 Fundamentos de programação

Antes de escrever código, é preciso entender **o que é programar**. Este módulo não exige nenhum conhecimento prévio.

| Aula | Conteúdo |
|---|---|
| [01. O que é programação?](01-o-que-e-programacao.md) | Programação, programa, algoritmo, código-fonte, linguagens, compilação e interpretação |
| [02. Lógica de programação](02-logica-de-programacao.md) | Sequência lógica, variáveis, constantes, operadores |
| [03. Decisões e repetições](03-decisoes-e-repeticoes.md) | Condicionais e laços de repetição |
| [04. Funções, entrada e saída](04-funcoes-entrada-e-saida.md) | Dividir problemas em partes; conversar com o usuário |
| [05. Resolução de problemas](05-resolucao-de-problemas.md) | Um método para resolver qualquer exercício |

Cada aula tem: **explicação**, **exemplo simples**, **código executável**, **aplicação prática no ProgramaBot** e **exercício**.

> Para executar os exemplos, você precisa do Python instalado. Veja [Instalando o Python](../getting-started/01-instalando-o-python.md). Salve o código em um arquivo `.py` e execute com `python nome_do_arquivo.py`.

Depois deste módulo, siga para [Python](../python/README.md).
